# Unemployment Analysis in India

## About Project

This project analyzes unemployment in India using Python.

The main aim of this project is to understand unemployment rate, employment count, and labour participation rate based on different regions and areas.

## Dataset

Dataset used: `Unemployment in India.csv`

The dataset contains unemployment data of different Indian regions.

## Columns Used

- Region
- Date
- Estimated Unemployment Rate (%)
- Estimated Employed
- Estimated Labour Participation Rate (%)
- Area

## Tools and Libraries Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Work Done in This Project

- Loaded the dataset
- Checked dataset information
- Cleaned column names
- Checked missing values
- Analyzed unemployment rate by Area
- Analyzed unemployment rate by Region
- Analyzed labour participation rate
- Created visualizations
- Wrote final observations

## Main Analysis

### 1. Average Unemployment Rate

The average unemployment rate in the dataset is around **11.79%**.

### 2. Area-wise Analysis

The data was grouped by Area to compare:

- Estimated Unemployment Rate
- Estimated Employed
- Labour Participation Rate

### 3. Region-wise Analysis

The data was grouped by Region to compare unemployment conditions in different Indian regions.

### 4. Highest and Lowest Unemployment

- Highest average unemployment rate: **Tripura**
- Lowest average unemployment rate: **Meghalaya**

## Final Observations

- Unemployment was not equal in all regions of India.
- Some regions had higher unemployment compared to others.
- Urban and Rural areas showed different unemployment patterns.
- Labour participation rate also varied by region and area.
- This analysis helps understand unemployment trends using data.
